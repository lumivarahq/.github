**Lumivara** is an AI-native software studio. We build SAP modernization tooling, learning
platforms, AI agents, and marketplace products — designed, shipped, and operated by a lean,
AI-augmented engineering operation. Nothing here is a slide deck: everything below is deployed.

### Flagship — SAP × AI

Most ABAP tooling still assumes a live SAP system. [abap-mcp](https://github.com/palimkarakshay/abap-mcp)
is an open-source MCP server that gives any AI assistant offline ABAP analysis, Clean Core readiness
checks, and RAP scaffolding — and [RAP Dojo](https://academy.lumivara.tech) is an interactive academy
that teaches Clean Core ABAP with an AI coach built on that same toolchain.
